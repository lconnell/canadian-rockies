# Google My Maps imports

Import each CSV below into its own Google My Maps layer. Google My Maps does not create layers from a `Layer` column inside one CSV.

1. `01-banff-lake-louise.csv`
2. `02-yoho-golden.csv`
3. `03-icefields-parkway.csv`
4. `04-jasper-mount-robson.csv`
5. `05-calgary-logistics.csv`

For each layer, choose `Address` as the position column and `Name` as the marker title.
